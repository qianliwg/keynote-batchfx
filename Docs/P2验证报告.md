# Keynote 动效工坊 P2 验证报告

验证目标：把任意当前幻灯片上的根级曲线控制点导入动效项目，并把选定的根级目标对象写回一个新的 Keynote 副本。

## P2 已完成

- 适配器新增 `extractRoute` 接口，返回画布尺寸、来源指纹、路线对象编号、目标对象编号和连续三次贝塞尔控制点。
- 适配器新增 `applyMotion` 接口，复用原生沿线动画生成器，在来源指纹、媒体引用和输出文稿结构校验通过后才发布副本。
- macOS 界面新增路线/目标对象选择、时长、同步绘制、沿切线旋转、导入曲线和写回副本控制。
- 导入真实路线后，P1 预览项目会保存幻灯片和对象编号，重新打开项目仍保留这些关联信息。
- 项目 Schema 允许保存 P2 对象编号，同时兼容没有对象编号的 P1 项目。

## 验证结果

- `extractRoute` 在两段 Keynote 曲线上返回 1 段贝塞尔路线和正确的对象编号。
- `applyMotion` 在测试副本中生成新文稿，输出媒体完整性检查通过，原始文稿字节未改变。
- P2 适配器回归测试覆盖来源过期、已有输出、未知接口、中文素材、路线导入和动画写回。
- 原生应用自检、P0/P1 运动数学和既有适配器测试继续作为发布前门槛。

## 当前边界

本报告记录的 P2 基线只处理当前幻灯片的根级对象；P2.2 已在
`Docs/P2.2验证报告.md` 中补上根级群组、项目导出和替换动画保护。跨组件对象、复杂多段路径、逐帧画面差异测量和项目批量导出仍留给后续版本。
