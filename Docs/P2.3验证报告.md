# Keynote 动效工坊 P2.3 验证报告

验证日期：2026-10-21。P2.3 把停靠、分段速度和反向运动从示例工程设置变成预览页可编辑、可保存的时间线。

## 本版完成

- 预览页新增分段时间线编辑器，每段可修改时长和目标进度。
- 时间线自动重新计算连续的 `start` 与下一段 `from`，避免分段之间出现断点。
- 提供全程、两次停靠、三段速度和反向四个快速模板。
- 停靠用相同的 `from/to` 表示，反向用较小的 `to` 表示；这些设置与路线绘制和目标姿态共用同一个时间函数。
- 限制最多 32 段、总时长最多 600 秒，非法输入不会写入项目。
- 版本升至 `0.3.3`，应用包和测试资源路径同步更新为 P2.3。

## 验证结果

```text
./Packaging/build.sh --runtime
./Verification/run_checks.sh
```

Swift 运动自检、隔离运行时和 Python 17 项协议/导出测试继续通过。项目文件仍兼容 P1/P2 的 `formatVersion: 1` 结构，时间线字段没有改变。

## 当前边界

分段时间线现在可以编辑、预览和保存。P2.3 的原生 Keynote 副本导出仍要求单段、单次播放；导出按钮会明确提示，避免把停靠、分段速度或反向设置静默转换成一段直线动画。下一版将把已验证的分段时间线编译成多个原生动画块，并用 Keynote 导出影片检查顺序与停靠时长。
