# Keynote 动效工坊 P2.2 验证报告

验证日期：2026-10-20。P2.2 把已保存的 `.kmotion.json` 项目直接编译成新的 Keynote 副本，并加入群组目标、固定朝向锚点和替换已有动画的保护流程。

## 本版完成

- 新增 `exportProject` 协议：读取项目指纹、路线、画布和目标尺寸，全部匹配后才生成副本。
- 目标可以是根级图片、影片、形状或群组；群组内部对象和媒体引用随副本保留。
- 非中心贴线点支持固定朝向导出；路线切线朝向仍要求中心贴线点，避免悄悄改变用户设置。
- 默认拒绝覆盖已有输出和已有动画；勾选替换后只移除所选路线/目标关联的动画。
- 导出写入同卷临时包，再用独占硬链接发布，来源文稿变化或校验失败时不会留下半成品。
- 内置 Python 运行时在 `-I -S` 隔离模式下可加载新导出模块，应用不依赖外部 Python 环境。

## Keynote 原生验证

在 Keynote Creator Studio 15.4 中重新打开并导出群组副本，输出影片为 1920×1080、30 fps。群组中的图片、文字和箭头在重存后的 `.key` 中仍可读取，未出现图片丢失。

固定朝向和路线切线朝向副本均完成打开、保存和导出。固定朝向视频共跟踪 331 帧，标记点到几何路线的最大距离约 1.36 点，中位数约 0.91 点；这是图像识别得到的几何距离，不能当作 Keynote 帧时间同步误差。后续若要把同步误差变成发布门槛，需要建立路线笔尖和目标对象的逐帧标注测量。

## 当前边界

停靠、分段速度、往返和循环已经可以在预览中编辑，但当前原生副本导出要求单段、全程、单次播放。非中心锚点的路线切线旋转也暂时拒绝导出。下一步适合做多组动画工程和原生分段时间线，而不是放宽校验后静默丢失设置。
