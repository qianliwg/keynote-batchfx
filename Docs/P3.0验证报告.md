# Keynote 动效工坊 P3.0 验证报告

P3.0 将六类视频动效工具合并到同一份 `.kmotion.json` 项目：模拟镜头运镜、分层视差、文字动效编排、阵列与波浪、声音卡点和循环动效。

## 本版完成

- 镜头：中心关键帧、缩放关键帧和推近/跟随预设。
- 视差：可添加多层、调整深度和偏移，预览按目标运动计算层间差异。
- 文字：可添加多个文字段，设置内容、开始时间、时长、淡入和缩放。
- 阵列与波浪：可设置实例数量、间距、幅度、频率和相位。
- 声音卡点：可关联音频文件，以 BPM 和偏移生成节拍标记并在预览中显示。
- 循环：可设置循环次数，并与循环/往返播放模式组合预览。
- 所有设置都写入项目文件；旧版项目缺少 `effects` 字段时自动使用关闭状态。

## 当前边界

P3.0 已完成编辑、保存和预览，但高级效果尚未编译成 Keynote 原生动画轨道。生成副本时会明确提示，避免静默丢失镜头、视差、文字、阵列、节拍或多次循环设置。基础单段沿线动画的原生副本流程保持不变。

## 验证命令

```text
./Packaging/build.sh --runtime
./Verification/run_checks.sh
```

运动自检覆盖镜头、阵列、文字和节拍模型；Python 集成测试继续覆盖素材保留、来源指纹、并发输出和原生副本保护。
