# keynote-batchfx

Keynote 动效工坊：用 Keynote 中已画好的曲线驱动图片、形状或群组，减少手动调整运动路径的工作。

当前是 P3.0 开发版（0.4.0），支持在 macOS 上导入、预览、保存项目、编辑分段时间线，并提供视频动效预览工具。

## 使用流程

1. 在 Keynote 中保存文稿；路线应是单条开放、可编辑曲线。
2. 在应用的「文稿与对象」页打开文稿，选择路线和目标，点击「导入到预览」。目标可以是整个嵌套群组。
3. 到「预览与导出」页调整时长、贴线点、朝向、同步描线和分段时间线；停靠用相同的 from/to，反向用较小的 to。
4. 在「视频动效工具」中组合镜头运镜、分层视差、文字编排、阵列波浪、声音卡点和循环次数。
5. 保存 `.kmotion.json` 项目。再次打开时，应用检查来源指纹并恢复幻灯片、路线、目标和全部特效设置；文件移位后可以重新关联内容一致的文稿。
5. 点击「生成副本」。若选中对象已有动画，需要明确勾选替换；原文稿和其余对象的动画保留。

## 当前支持范围

| 设置 | 应用内预览 | Keynote 副本 |
| --- | --- | --- |
| 单段移动与同步描线 | 支持 | 支持，原生插值与预览仍需进一步对照 |
| 固定朝向、任意边框贴线点 | 支持 | 支持，保留导入时朝向 |
| 沿线转向、中心贴线 | 支持 | 支持 |
| 沿线转向、非中心贴线 | 几何示意支持 | 尚未开放，导出会提示 |
| 普通与嵌套群组整体移动 | 边框示意 | 支持根级群组，成员自身动画会阻止导出 |
| 单次 / 循环 / 往返 | 支持，进度条覆盖完整往返周期 | 当前只导出单次 |
| 项目中的停靠 / 分段时间 | 支持编辑、预览和保存 | 当前导出会明确提示，尚未写入原生时间线 |
| 模拟镜头运镜 | 支持关键帧缩放、平移和推近/跟随预设 | 高级效果当前保存于项目并在预览中播放 |
| 分层视差动画 | 支持层深度、偏移和预览 | 高级效果当前保存于项目并在预览中播放 |
| 文字动效编排 | 支持文字段、起始时间、时长、淡入和缩放 | 高级效果当前保存于项目并在预览中播放 |
| 阵列与波浪动画 | 支持数量、间距、幅度和相位 | 高级效果当前保存于项目并在预览中播放 |
| 声音卡点 | 支持关联音频、BPM、偏移和节拍标记 | 高级效果当前保存于项目并在预览中播放 |
| 循环动效制作 | 支持循环次数与循环/往返组合预览 | 高级效果当前保存于项目并在预览中播放 |

预览橙色块表示对象/群组边框，不包含真实图片内容、裁切或 GIF 帧。贴线点按边框坐标定义。原生副本仍应在 Keynote 中播放检查；不承诺所有 Keynote 版本、复杂变换组合与未知对象兼容。

## 构建与验证

开发构建需要 Apple Silicon Mac、Xcode 命令行工具，以及 python.org 的 macOS universal2 Python 安装。本机验证运行时为 CPython 3.13.7；构建脚本依赖其 framework 目录结构。最终 app 内置 Python，运行时不需要用户安装这些开发环境。

```bash
./Packaging/build.sh --runtime
./Verification/run_checks.sh
```

构建结果在 `dist/Keynote动效工坊-P3.0.zip`（内部版本 0.4.0）。使用临时本地签名，尚未做 Developer ID 公证。最低编译目标 macOS 14，当前只在本机验收。

公开仓库不包含本地 Keynote 文稿、图片、视频和安装包。缺少样例时仍可构建；依赖样例的测试明确跳过，其余协议与数学检查照常执行。旧版沿线工具的外部回归测试留在本地执行，公开仓库不要求存在兄弟目录。

## 目录

- `App/`：SwiftUI 界面与项目恢复。
- `MotionCore/`：路线采样、时间、姿态和项目校验。
- `KeynoteAdapter/`：文稿解析、原生动画编译、媒体校验与副本发布。
- `ProjectFormat/`：项目 Schema 与示例。
- `Packaging/`：运行时和应用打包。
- `Verification/`：协议、运动数学、项目导出和文件保护测试。
- `Docs/`：各阶段验证记录及边界。
